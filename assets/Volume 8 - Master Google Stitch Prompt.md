# NOMAD UI DESIGN BIBLE

## Volume 8 — Master Google Stitch Prompt (v1.0)

You are an award-winning Senior Product Designer, UX Designer, and Design System Architect.

Design a premium desktop-first web application called **Nomad**.

Nomad is a modern outdoor gear ecosystem where users can purchase outdoor equipment, rent premium gear, read educational journals, discover curated collections, and manage their outdoor adventures.

The application should feel like a combination of Patagonia, Arc'teryx, REI, Fjällräven, Airbnb, Apple, Stripe, and Linear.

Do NOT copy any of these brands.

Only use them as inspiration for quality, spacing, simplicity, and premium user experience.

# UX Principles

Design for exploration.

Reduce cognitive load.

Keep navigation predictable.

Use photography as the primary storytelling element.

Encourage users to browse naturally rather than aggressively pushing sales.

Support both purchasing and rental equally.

Every page should feel connected as one continuous journey.

---

# Overall Experience

The final design should feel like browsing a premium outdoor lifestyle publication rather than a traditional e-commerce website.

The interface should be elegant, calm, spacious, and timeless.

Every screen should reinforce trust, inspire adventure, and make users excited to plan their next journey.

Deliver a polished, production-ready design system with consistent components, spacing, typography, color usage, and interactions across all fourteen pages.

The final result should be suitable for implementation in **Next.js + Tailwind CSS + shadcn/ui + Framer Motion**, using reusable components and a scalable design system.
